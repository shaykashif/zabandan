# Zabandan

A word-by-word reader for classical Urdu ghazals and nazms. Tap any word to see what it means in that couplet, with literal and poetic English translations and notes on cultural context and double meanings. The site is published at [zabandan.shaykas.com](https://zabandan.shaykas.com).

Translations and word meanings are generated by an LLM (DeepSeek V4 Pro via OpenRouter), checked automatically for completeness, and reviewed by hand.

## Layout

- `scripts/annotate_poem.py`: annotates a poem word by word (`curate_notes.py` then trims the notes to cultural context and double meanings)
- `scripts/build_site.py`: builds the static site into `site/` from `site_src/` and `data/annotated/`
- `data/nazms/`: nazm texts with sources and citations; ghazals come from the corpus in `data/processed/`
- `data/glossary.yaml`: conventional terms of Urdu poetry, sent with every annotation request
- `config/models.yaml`: models and roles
- `scripts/run_baseline.py`, `results/`: the model comparison that chose the default model
- `site/`: the built site, committed; the Oracle server serves it with nginx (`deploy/`, `DEPLOY.md`)

## Quick start

```bash
pip install pyyaml
echo "OPENROUTER_API_KEY=your-key" > .env
python scripts/annotate_poem.py parinde-ki-faryad   # a nazm in data/nazms/, or part of a ghazal's corpus id
python scripts/curate_notes.py
python scripts/build_site.py
python -m http.server 8766 --directory site         # http://localhost:8766
```

To rebuild the ghazal corpus, clone [urdu_ghazals_rekhta](https://github.com/amir9ume/urdu_ghazals_rekhta) into `data/raw/` and run `scripts/build_corpus.py`.
